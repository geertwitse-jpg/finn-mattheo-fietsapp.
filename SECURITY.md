# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository, if enabled, to report a suspected vulnerability privately.

This project is a static GitHub Pages website. Do not submit passwords, access tokens, API keys, or personal information in issues or pull requests.

## Scope

The website currently contains a client-side profile gate for convenience only. It is not secure authentication. Never use it to protect confidential information.
